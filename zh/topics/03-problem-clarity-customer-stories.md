# 問題清晰度與客戶故事
{: .no_toc }

*約 8 分鐘*

**🎯 面試高頻**

## 為什麼重要

YC 面試常常在第一分鐘就變成「跟我講一個用戶」。早期 VC 盡職調查會變成「我們能不能跟一個聊聊」。一個類別描述（「SMB 在營運上很辛苦」）不是故事。故事裡有一個人、有上一次、有替代做法、有代價。如果你講不出一個，partner 會假設你還沒有把這個點子賺到手。

## 核心概念

- **一個用戶、一件工作、一個時刻。** 他們是誰（角色、情境）、問題上次發生是什麼時候、他們做了什麼、代價是什麼、他們已經試過什麼。五句話。一張有人口統計的 persona 投影片不是這個。
- **過去的行為，不是假設性的喜歡。** 「你會用這個嗎？」換來的是禮貌的會。「帶我走一次你上次做這件事」換來的是證據。Rob Fitzpatrick 的 *The Mom Test* 是短版：談他們的生活，不要談你的點子。問具體的事。對話前半段不要 pitch。
- **替代做法，是你忘了的那個競爭者。** Excel、一條 WhatsApp、一個 VA、他們已經在付錢的工具裡的一個模組，或什麼都不做。把它講出來。「他們沒有解決方案」很少是真的。「他們討厭那個解法，但還是在用」才是故事。
- **在 B2B，用戶、買家、和 champion 是不同的工作。** 痛的那個人可能沒有預算。說誰感受到、誰簽字、誰可以擋住。如果你只認識用戶，就這樣說。見 [Go-to-market](../08-go-to-market-story/)。
- **一個沒有帶來改變的計數，是虛榮指標。** 「我們聊了 30 個人」有意義，是在你能說出之前相信什麼、他們說了什麼、你因此砍掉或做出什麼。三個改變了產品的對話，勝過三十個只是確認 pitch 的對話。
- **每個房間怎麼用這個故事。** 在 YC 面試，一個鮮明的客戶常常就是全部的答案，而且他們會追問一個你只有真的在場才答得出來的問題（「你給她看價格時，她說了什麼？」）。在 seed 盡職調查，預期要把那個客戶介紹出去，所以故事必須是真的，而且那個人願意講。

## 心智模型

```
誰（具體的人）→ 上次發生是什麼時候 → 他們當時怎麼做 → 代價是什麼 → 你因此改了產品的哪一塊
```

跳過「上次」，你是在 pitch。跳過「你改了什麼」，你是在蒐集軼事。

## 面試問題

1. **跟我講一個真實用戶。**
   答：即使不講名字，也要講情境。「一所 40 人學校的設施管理員；上個月廠商匯出漏了兩間教室，她用試算表把課表重排了一遍；花了她四小時；她還是續約了，因為換掉更糟。」然後一句話：她在用你的什麼，或為什麼還沒用。停。讓他們拉。

2. **你跟多少客戶聊過，學到什麼？**
   答：數字、他們是誰（所以不是朋友在客氣），以及一個你改掉的信念。「十二個診所的行政，不是我們同學。我們以為痛在帳單代碼。其實是 prior-auth 的 PDF。我們砍掉 dashboard，做出 PDF 那條路。」一個沒有改變的數字，讀起來像觀光。

3. **你聊到的每個人都說喜歡這個點子。為什麼那不夠？**
   答：喜歡一個點子很便宜。使用替代做法、付錢、或在行事曆上給你一個固定時段，不便宜。報告行為：他們付了、他們又出現、他們介紹了同儕，或他們沒有。用戶訪談裡的喜歡，是 *The Mom Test* 叫你打折的那個東西。

4. **你的用戶和買家是不同的人。怎麼解釋，才不會聽起來像你沒有客戶？**
   答：兩個都說，並說你在哪一個上面有證據。「護理師每一班都撞上這個問題。護理主任買單。我們看過四個護理師做那個替代做法，也做過兩次購買對話，其中一次變成 pilot。」把這個分裂藏起來，比把它講出來更糟。
