# 競爭與差異化
{: .no_toc }

*約 8 分鐘*

**🎯 面試高頻**

## 為什麼重要

「你跟誰競爭？」是一個真話測試。創辦人不是說沒有人，就是拿出一張勾選矩陣，自己那一欄是唯一全勾的。兩個答案都告訴 partner，你沒有用過那些替代方案。真正的集合是：現有廠商、試算表或實習生、這個類別裡的其他新創，以及什麼都不做。差異化是一個具體的用戶在這一季換過來的理由，而且在一個軸上。

## 核心概念

- **把集合大聲講出來。** 現有產品（以及他們已經在付錢的那一個）。替代做法。其他新創，包括明顯的「AI for X」鄰居。現狀。如果你叫不出兩家公司和一個不是公司的東西，你還沒準備好這個問題。
- **現狀通常贏。** 轉換有成本：時間、風險、一個被打破的習慣、一份合約。你的答案應該包括為什麼有人現在移動，不是為什麼你的功能清單比較長。一個觸發（續約、新法規、一個很糟的季度）比「我們比較好」強。
- **一個軸，用戶看得到。** 在他們計時過的那件工作上更快。便宜的方式會出現在他們的預算裡。去年還不可能、而他們已經在做的那一步，現在變成可能。「我們的 AI」和「更好的 UX」不是軸，直到你說出用戶停止做什麼。
- **護城河是比較後面的主張。** 早期你有的是領先、通路優勢，或一個在一件工作上明顯更好的產品。網路效應、資料護城河、品牌，是你也許賺得到的東西。在有之前就宣稱，是常見的破綻。Thiel 的課談的是靠擁有一個小市場來逃離競爭。那是 wedge，不是你在第一年可以主張的護城河。見[市場規模與 wedge](../05-market-size-wedge/)。
- **用過競爭者。** Partner 喜歡「我們用了他們一週，斷點在這裡」。他們不信任一張從競爭者行銷網站做出來的矩陣。
- **房間的差別。** YC 要的是那個集合，以及你會贏的理由，幾句話，加上你碰過替代方案之後學到的東西。Seed 盡職調查會追「什麼阻止現有廠商在一年內做出這個？」要有一個不是「我們更有熱情」的答案。結構性的理由（他們服務這個客群就會打破核心定價、這個工作流程低於他們的 ACV、你擁有他們沒有的通路）才是活得下來的那個。

## 心智模型

```
他們今天用誰 → 為什麼那個仍然贏 → 你更好的那一個軸 → 為什麼現有廠商不直接複製那個軸 → 你還沒有在主張的是什麼
```

照這個順序走。矩陣是選用的，而且通常更糟。

## 面試問題

1. **你的競爭者是誰？**
   答：三層。「今天他們用［現有廠商］加一份試算表。［那家新創］把一套更廣的產品賣給更大的買家。什麼都不做仍然是最常見的選擇，因為痛是每月，不是每天。」然後那個軸。不要用「我們其實沒有競爭者」開場。

2. **為什麼［大公司］不直接做這個？**
   答：一個綁在他們生意上的結構性理由，不是羞辱。「他們的 ACV 是企業年約。這個買家是 $6k 的信用卡購買，服務他們代表一種自助，跟他們業務怎麼拿獎金衝突。」如果你沒有那個理由，就說你真正的領先是什麼（對這個用戶的速度、一個他們忽略的工作流程），不要把它打扮成永久的護城河。

3. **你的投影片說你是唯一六個功能都有的。這個答案哪裡錯？**
   答：用戶不買一整欄勾勾。他們買一件工作上的解脫。挑那件工作，說你怎麼知道替代方案在那裡失敗，然後把格子丟掉。一整欄勾勾通常代表功能是為了贏下那張投影片而選的。

4. **Partner 說這個領域很擠，你晚了。**
   答：不要抽象地爭「擠不擠」。說用戶拿你跟誰比、那些選項留下哪個具體缺口、你已經贏到什麼（一個 design partner、一個重複的工作流程、一條通路）。晚於一輪媒體週期，仍可能早於一個買家。沒有 wedge 的晚，就是晚。見 [Why this / why now / why you](../02-why-this-why-now-why-you/)。

## 觀看

- [Competition is for Losers with Peter Thiel (How to Start a Startup 2014: 5)](https://www.youtube.com/watch?v=3Fx5Q8xGU8k) — Y Combinator。為什麼「我們要在一個巨大市場裡競爭」是弱計畫，以及擁有一個小市場是為了什麼。跟[市場規模與 wedge](../05-market-size-wedge/)一起看。
- [Michael Seibel on how to create a great startup pitch](https://www.youtube.com/watch?v=UrdqXffoOUo) — Startup Archive。獨特 insight 和「你怎麼賺錢」的標準：用一兩句話講尖的版本，不要把每個可能的角度都列出來。

## 延伸閱讀

- [How to Get Startup Ideas](https://paulgraham.com/startupideas.html) — Paul Graham。關於注意到別人錯過的點子，因為它看起來像苦工，或一個很小的開始。
- [Why Founders Shouldn't Think Like Investors](https://www.ycombinator.com/library/Kk-why-founders-shouldn-t-think-like-investors) — Dalton Caldwell 與 Michael Seibel，YC Startup Library。包括因為一張市場地圖說這個空間是空的，所以選了這個點子的失敗模式。
