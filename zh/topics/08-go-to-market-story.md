# Go-to-market
{: .no_toc }

*約 8 分鐘*

**面試偶爾會問**

## 為什麼重要

「你怎麼拿到客戶？」通常是一場較長面試裡的一個問題，除非通路就是全部的風險。創辦人用一張清單回答：內容、合作、病毒、付費、業務。Partner 要的是你已經跑過的那個動作，帶一個計數，以及你認為會重複的那一個動作。一條你還沒試過的通路是假設。就這樣標。

## 核心概念

- **先講已經發生的手動做法。** 你怎麼找到第一批用戶、多少對話、多少變成使用或付款。創辦人自己賣、以及不能規模化的接觸，是正確的早期動作，不是丟臉。Paul Graham 的 “Do Things that Don't Scale” 是那篇文章。Gustaf Alströmer 的課是另一側的警告：不要把付費獲客灌在一個留不住的產品上。
- **一條通路，不是一個組合。** 說通路、你碰到的人、觸發、以及它花掉的創辦人時間。「現有廠商合約到期的那一週，我寫信給行政。一週大約 30 封，8 封回，2 通通話。」第二條通路可以是你正在測試的一句話。五條通路代表你還沒選。
- **B2B：講出職稱和路徑。** 你聯絡誰、他們為什麼回、從第一封信到付費或 pilot 實際花了多久，以及還有誰必須點頭。如果你只做過兩次，週期就是「我們看過兩次」，不是你讀到的產業平均。
- **消費產品：說前一百個怎麼來的，以及你不戳他們時他們回不回來。** 上線的尖峰是通路測試。Retention 是產品。見 [Traction](../07-traction-metrics-under-fire/)。
- **付費是放大器。** 如果廣告是用戶出現的唯一方式，你是在租成長。之後可以沒問題，當你量過回本。早期，它是買一張圖的方式。如果真相是「retention 還沒到，所以我們還沒開付費」，就這樣說。這句比一個你編出來的 CAC 更強。
- **房間的差別。** YC 要手動的動作和學到的東西。Seed 投資人想聽到它開始在沒有英雄式創辦人努力的情況下重複，或一個清楚的理由：這一輪就是讓可重複的動作變成可能的東西（一個聘僱、一個整合、一個城市）。不要宣稱一個你沒有的銷售機器。

## 心智模型

```
這個月我們接觸得到誰 → 我們已經做了什麼（計數）→ 什麼轉化了 → 我們認為會重複的那一個動作 → 我們明確還沒花錢的是什麼
```

面試版本就是這個順序。五個 logo 的策略投影片，是你跳過的東西。

## 面試問題

1. **你怎麼拿到客戶？**
   答：動作、計數、轉換。「創辦人自己寄給診所行政。60 封信，15 封回，6 通話，2 個 pilot，1 個付費。那封信是一個具體的 prior-auth 例子，不是產品群發。」然後一句話：你認為什麼會規模化。如果還沒證明，標成信念。

2. **你的 CAC 是多少？**
   答：只有在你有真的分母時才答。「我們還沒有為通路付過錢。成本是創辦人的時間，我不會假裝那是 CAC。」如果你有花：「我們在一份電子報上花了 $1,200，得到 3 個 trial，0 個付費。那是一個失敗的測試，不是一個可以外推的 CAC。」假的 LTV/CAC 是陷阱。見[常見陷阱](../12-common-traps-weak-answers/)。

3. **為什麼不直接投廣告？**
   答：因為廣告會放大產品已經在做的事，包括「人不會回來」。這是 Alströmer 的重點。說什麼必須先是真的（一個重複的行為、一個你相信的回本），以及這個月你改做什麼。

4. **Partner 說創辦人自己賣不能規模化。**
   答：同意，並標出你在哪。「它不能規模化，而這是我們學會 pitch 和買家的方式。我們在看的可重複片段是：第二家診所會不會在我不在通話上的情況下，對同一封信說好。這一輪請一個人來跑那封信，不是一個行銷團隊。」規模化是你應該指名的後面的問題，不是一個你應該假裝已經解決的問題。
